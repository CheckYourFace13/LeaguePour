# Acquisition program tooling

Owner page: `/internal/acquisition` on leaguepour.com (owner login only).

## How it works

- **Attribution.** `src/components/analytics/acquisition-capture.tsx` stores the first landing's UTM parameters, outreach `ref` token or external referrer in the first-party cookie `lp_acq` (60 days, no personal data). `/api/register` saves it for each new venue (`AppSetting acq:venue:<venueId>`) and links the venue to the outreach prospect it came from.
- **Prospects.** The researched list is **not** in this repository, because the repo is public. The owner keeps it in the gitignored `private/acquisition/` folder and uploads the JSON on the owner page. Import validates every row (public source, verification date, contact route; email only when the business publishes one). It dedupes against existing venues, the older outreach list and every opt-out, bounce or complaint. Matches are stored as Suppressed, with the reason.
- **Approval.** Nothing sends automatically. Each prospect needs **Approve** and then **Send**: one click each, at most 20 per brand per Chicago day. Each send carries a Resend idempotency key, and the row is claimed first so a double click can't send twice. Sends refuse without `OUTREACH_POSTAL_ADDRESS`.
- **Compliance.** Every email states the true sender and why it was sent, and includes the postal address, an unsubscribe link and `List-Unsubscribe` one-click headers. Unsubscribing (`/api/acquisition/unsubscribe`) also stops both older outreach lanes. Resend bounce and complaint webhooks suppress prospects too.
- **Dashboard.** LeaguePour and VenueSprocket are shown separately. Each shows prospects, contact attempts, replies (marked by the owner), positive replies, tracked-link visits, registrations (total and from outreach), activated venues, tournaments, paid conversions, new and attributable MRR, unsubscribes, bounces and complaints, plus targets.
- **Older VenueSprocket daily cold email.** Paused on 2026-11-21 by owner decision, behind the default-off setting `vs_outreach_enabled_after_2026_11_pause`. Turn it back on from `/internal/outreach`.

- `npx tsx scripts/check-acquisition.ts` runs offline. The prospect-data checks run only when the private file is present.
- `TEST_DATABASE_URL=postgresql://postgres@127.0.0.1:<port>/<db>?schema=leaguepour_lp npx tsx scripts/check-acquisition-db.ts` needs a throwaway local Postgres.
